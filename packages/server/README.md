# Atoyr Server (Go + Gin + GORM)

A high-performance backend for the Atoyr word game, built with Go using Gin framework and GORM ORM.

## Architecture

### Technology Stack

- **Language**: Go 1.21+
- **Web Framework**: Gin 1.9.1
- **ORM**: GORM 1.25.5
- **Database**: SQLite
- **UUID Generation**: google/uuid v1.6.0
