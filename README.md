# A Test of Your Reflexes

A Test of Your Reflexes, or Atoyr, is a game where the users will see 5 characters in a random order and they will need to re-order those into a correct word, given a definition of the word.

## Requirements

- Node.js 24 or above
- Go 1.25 or above
- [Air](https://github.com/air-verse/air) installed with `go install github.com/air-verse/air@latest`
